# Dunyi Zhou — Academic Homepage

Personal academic homepage of Dunyi Zhou (BUPT), built with [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com), deployed on GitHub Pages.

Design language inspired by the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme (see `CLAUDE.md` for the full list of references).

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # production build → dist/
```

## Content

All content lives in `src/content/` (Markdown + frontmatter) and `src/data/profile.ts`. See `CLAUDE.md` for details.
